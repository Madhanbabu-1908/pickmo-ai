# ⚙️ Pickmo.ai – Backend

**Pickmo.ai backend** is a Node.js + Express server that aggregates **free AI models** from Groq, OpenRouter, and Google Gemini. It provides a unified streaming chat API, per‑conversation **RAG (document retrieval)**, optional **web search**, PII guardrails, and email feedback – all designed to be lightweight and free‑tier friendly.

🔗 **Frontend repository:** [github.com/Madhanbabu-1908/pickmo-ai-frontend](https://github.com/Madhanbabu-1908/pickmo-ai-frontend)

---

## ✨ Key Features

### AI & Chat
- 🧠 **Dynamic model fetching** – automatically discovers free models from all providers (no hardcoded lists)
- 💬 **Streaming chat** – token‑by‑token responses for Groq, OpenRouter, and Google Gemini
- 🖼️ **Multimodal support** – accepts text + base64 images (Gemini, some OpenRouter models)
- 🔁 **Retry logic** – automatic exponential backoff for Google 429 rate limits

### RAG (Retrieval-Augmented Generation)
- 📚 **Per‑chat document storage** – each conversation has its own isolated document store
- 🧮 **Embeddings** – simple char‑code embedding (lightweight) or optional Transformers.js (more accurate)
- 🔍 **Vector similarity search** – returns top‑3 most relevant chunks using cosine similarity
- 💾 **Optional disk persistence** – documents survive server restarts when `SAVE_DOCUMENTS=true`

### Security & Privacy
- 🛡️ **PII guardrail** – blocks emails, phone numbers, credit cards, Aadhaar, PAN from reaching AI APIs
- 📧 **Feedback email** – Help & Support messages sent via SMTP (Gmail, SendGrid, etc.)
- 🔒 **No message logging** – chat history never stored on the server (only in‑memory for RAG, optional disk backup)

### Additional Utilities
- 🌐 **Web search** – free DuckDuckGo HTML scraping, injected as system context
- 🎯 **Auto‑title generation** – uses Groq to create short titles for new conversations

## 🚀 Getting Started (Development)

### Prerequisites
- Node.js 18+
- Free API keys:
  - [Groq](https://console.groq.com) – instant, high limits
  - [OpenRouter](https://openrouter.ai/keys) – 50+ free models
  - [Google Gemini](https://aistudio.google.com/) – generous free tier

### Clone & Install

```bash
git clone https://github.com/Madhanbabu-1908/pickmo-ai.git
cd pickmo-ai
npm install
```

### Environment Variables

Create a `.env` file:

```env
PORT=10000
GROQ_API_KEY=gsk_xxxxxxxxxx
OPENROUTER_API_KEY=sk-or-xxxxxxxxxx
GOOGLE_API_KEY=AIzaxxxxxxxxxx

# Email (for feedback)
FEEDBACK_EMAIL=your@email.com
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@gmail.com
SMTP_PASS=your_app_password

# Embeddings: 'simple' (low memory) or 'transformers' (better, needs more RAM)
EMBEDDING_MODE=simple

# Optional: persist RAG documents across restarts
SAVE_DOCUMENTS=true
```

### Run Development Server

```bash
npm run dev   # nodemon auto‑restart
# or
npm start
```

Server runs on `http://localhost:5000` (Render uses `PORT` variable).

## 📡 API Endpoints

### Public

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/health` | Health check + stats |
| `GET` | `/api/models` | List all available free models |
| `POST` | `/api/models/refresh` | Force refresh model cache |
| `POST` | `/api/chat/stream` | Streaming chat (body: `{modelId, messages, enableSearch?}`) |
| `POST` | `/api/chat/title` | Generate short title (body: `{message, modelId?}`) |
| `POST` | `/api/feedback` | Send feedback/suggestion (body: `{type, message}`) |

### RAG (per‑chat)

All RAG endpoints require a `chatId` (generated by the frontend) to isolate documents per conversation.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/rag/upload` | Upload a document (body: `{text, name, chatId}`) |
| `POST` | `/api/rag/search` | Search for relevant chunks (body: `{query, chatId}`) |
| `GET` | `/api/rag/documents/:chatId` | List all active documents for a chat |
| `DELETE` | `/api/rag/document/:chatId/:docId` | Remove a single document |
| `DELETE` | `/api/rag/delete/:chatId` | Clear all documents for a chat |

## 🔄 How It Works

### 1. Model Discovery

- **Groq:** calls `models.list()` – all models are free.
- **OpenRouter:** fetches `/models` endpoint, filters those with `:free` suffix or zero pricing.
- **Google:** fetches `/v1beta/models`, filters Gemini chat models using a regex (excludes paid/turbo/premium).
- Results are cached for 1 hour, then refreshed automatically.

### 2. Chat Streaming

- Frontend sends `{modelId, messages, enableSearch}`.
- Backend cleans messages (removes `id` property), applies PII guardrail.
- If `enableSearch=true`, it extracts the last user message, performs a DuckDuckGo search, and injects results as a system message.
- Calls the appropriate provider API with streaming enabled.
- For Google, implements retry logic on 429 errors (exponential backoff, max 3 retries).

### 3. RAG (Document Storage)

- Documents are embedded using either a simple char‑code method or Transformers.js (`all-MiniLM-L6-v2`).
- Embeddings and text are stored in a `Map` keyed by `chatId`.
- When searching, the query is embedded, then cosine similarity is computed against all document chunks in that chat.
- Returns top‑3 most similar excerpts.

## ☁️ Deployment (Render)

1. Push your code to GitHub.
2. Create a new **Web Service** on [Render](https://render.com).
3. Connect your `pickmo-ai` repository.
4. Use the following settings:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** Free
5. Add all environment variables (same as `.env`) under **Environment**.
6. Click **Deploy**.

Render will automatically redeploy on every `git push` to the `main` branch.

### Keeping the Free Tier Alive

The free tier spins down after 15 minutes of inactivity. To keep it warm:
- Set up a free [UptimeRobot](https://uptimerobot.com) monitor to ping `https://pickmo-ai.onrender.com/api/health` every 5 minutes.
